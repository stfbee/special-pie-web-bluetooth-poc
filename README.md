# Special Pie M1A2+: Android Web Bluetooth PoC

Статическое приложение без зависимостей и сборки. Подключение к FFF0 / подписка на FFF1, события старта/остановки, времена выстрелов и сплиты, демо и JSON-журнал. Данные остаются на устройстве и в выгружаемом файле.

## Запуск через USB

1. Включите отладку по USB на Android и разрешите компьютеру доступ.
2. Из этой папки запустите `python serve.py`. Сервер явно задаёт JavaScript MIME для `.mjs`, независимо от настроек Windows.
3. Выполните `adb reverse tcp:8765 tcp:8765`.
4. Откройте **http://localhost:8765** в Chrome на телефоне.
5. Включите Bluetooth телефона и Bluetooth таймера. Отключите таймер от других приложений, если соединение занято.
6. Нажмите «Подключить таймер», выберите устройство в диалоге Chrome. При необходимости разрешите доступ к устройствам поблизости / геолокации, если Android запросит его.
7. Запустите сессию на самом таймере. Сверьте число выстрелов и времена с его экраном. Остановите сессию; скачайте JSON.

Обычный HTTP по LAN-адресу компьютера не подходит: Web Bluetooth требует secure context. Для автономного запуска разместите файлы на HTTPS-хостинге. USB нужен только для доступа к локальному серверу; BLE-соединение идёт напрямую с телефона к таймеру.

## Проверки

`node --test protocol.test.mjs`

Демо показывает три выстрела: 1.25, 2.04, 4.36 с; сплиты —, 0.79, 2.32 с. Демо отключено при BLE-соединении. Проверка на устройстве: новая сессия сбрасывает таблицу; остановка с совпадающим ID меняет статус; разрыв соединения отображается; повторное подключение снова подписывается на FFF1.

## Границы PoC

- Удалённый старт/стоп и загрузка истории отсутствуют в спецификации. FFF2 не используется.
- Парсер ожидает один полный протокольный кадр на notification, как описано в спецификации. Другие форматы записываются в журнал как ошибка; фрагментация не предполагается без реального захвата.
- Неизвестный байт checksum не проверяется: его алгоритм не описан.
- Номер выстрела из протокола начинается с 0; интерфейс показывает с 1. Первый сплит неизвестен. При пропусках индексов или убывании времени сплит не вычисляется.
- При подключении посреди сессии её начало неизвестно. После разрыва история автоматически не восстанавливается.
- Вкладка должна оставаться открытой, экран включённым. Фоновая работа и восстановление после выгрузки вкладки не реализованы.
- Журнал ограничен последними 5000 записями, архив — 100 сессиями. После перезагрузки страницы данные исчезают: используйте экспорт.
- Реальная совместимость с моделью/прошивкой проверяется на физическом таймере; автоматические тесты проверяют только протокол и расчёты.

Источники: [протокол](https://github.com/jkesseler/sg-timer-led-display/blob/master/docs/timer-protocols/special-pie-ble.md), [Web Bluetooth в Chrome](https://developer.chrome.com/docs/capabilities/bluetooth).
